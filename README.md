# Drip

Drip：Xposed 兼容的注入框架，在LSPlant的基础上实现了较好的隐藏能力。

## 功能特性

- 兼容 libxposed API 100 / 101 / 102，以及 legacy 82 / 93
- 按应用作用域配置，支持多用户（应用分身）
- 提供 CLI 工具管理模块
- 模块独立日志：每个 Xposed 模块（应用）日志独立落盘、日志页独立展示（XposedBridge.log 采集，直接 Log 不采集）
- 完全静默模式（无任何日志输出）
- 注入与 hook 链路可观测

## 环境要求

- Android 9 及以上
- 任意root管理器 + 任意zygisk 已安装
- 刷入模块 ZIP 后重启设备

## 安装

1. 下载最新模块 ZIP
2. 在 任意root管理器 中刷入该 ZIP
3. 重启设备

## 开源说明

Drip 采用部分开源策略，在透明与保护核心技术之间取得平衡：

- **Manager 源码完全公开**  
  你可以在本仓库查看 Manager 的全部源码，包括界面、模块管理逻辑、配置持久化等。

- **核心注入实现为预编译闭源**  
  注入器、native hook 引擎等核心组件以二进制形式提供。闭源的理由是防止注入思路与反检测策略被快速逆向利用，从而保持对目标应用的不可见性。

- **行为层可审计**  
  尽管核心二进制闭源，但其行为边界是清晰可审的：
  - AIDL 契约、权限声明、文件访问范围均公开
  - 框架**无联网行为**，所有数据仅存储于设备本地
  - 不包含任何遥测、统计或数据上传功能

- **安全承诺**  
  我们承诺：Drip 不会收集、上传任何用户数据，所有处理均在设备本地完成。

## FAQ

### 为什么核心实现闭源？

Drip 的核心竞争力在于对目标应用的不可见性。一旦注入链路、混淆策略、反检测思路公开，将很快被检测方针对性封堵，导致框架失效。闭源是为了保护这一关键技术壁垒，同时我们保证所有可被观察的行为（文件、通信、权限）都是可审计且无害的。

### 怎么保证没有后门？

- **无联网**：Drip 运行时不会发起任何网络连接，你可以在安装后通过抓包或防火墙监控确认。
- **数据不离设备**：所有配置、模块、日志均存储于设备本地，不存在上传通道。
- **行为契约公开**：我们公开了框架的 AIDL 接口和权限列表，任何安全研究者都可以静态分析预编译二进制来验证其行为是否符合声明。

### 怎么确认官方产物没有被篡改？

每个 release 都会附带 **SHA-256 校验和**，你可以：

1. 从官方渠道下载模块 ZIP 和校验文件
2. 计算本地文件的 SHA-256
3. 与官方公布的校验和进行比对

我们建议在安装前务必进行校验，以确保产物完整性。
